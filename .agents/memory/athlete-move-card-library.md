Viral Reel remains the project name and preserves its original design and ten existing feature areas. Replit is the hosting platform; custom domain is undecided. Stage 1 of the Pro Athlete Move Card Library targets 500 cards across all sports. The library is expandable and searchable by athlete, sport, and signature move. Participants may optionally choose “Cover This Move” or submit an original move; multiple participants can attempt one professional move.

AI-assisted generation from reference videos must create drafts. The owner-approved reference flow includes a private, searchable library of uploaded clips with provenance and permission metadata. Keep source files owner-only; analyzing a saved clip requires an explicit owner action and confirmed permission. Each move requires accurate verification, owner editing/approval, and appropriate media permissions before publication. Preserve the existing card design and competition system.

**Why:** The user explicitly approved this Stage 1 feature and later chose a searchable source-clip library as an add-on.

**How to apply:** Treat reference-based AI suggestions as drafts until an owner verifies the move and media permissions, then explicitly publishes. Never assume a public clip is licensed for reuse. Keep many submissions attached to one professional card; do not merge participant attempts into official standings or results unless existing competition rules explicitly do so.
